# Security Policy

## Supported versions

This repository contains organization-wide community files and has no versioned releases. Only its current `main` branch is maintained.

AuthModules packages are still in private pre-release development. Package-specific support policies will be published with their repositories and first releases.

## Reporting a vulnerability

Use GitHub private vulnerability reporting in the affected public repository. Until package repositories are published, organization-wide reports may be submitted privately through this repository. Do not open a public issue containing exploit details, credentials, tokens, personal data, or provider responses.

Include the affected package and version or commit, impact, reproduction conditions, and any suggested mitigation. Reports will be acknowledged and triaged before public disclosure.
